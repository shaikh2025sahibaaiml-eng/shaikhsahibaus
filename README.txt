SHAIKH SAHIBA WEBSITE - STARTER
Open index.html in a browser to preview.

Included:
- Responsive homepage
- Latest posts automatically appear first
- Categories and search
- Like, save, share
- Comments with pending moderation
- Admin dashboard prototype for publishing posts and moderating comments

Important:
This is a front-end prototype. Data is stored in the browser's localStorage, so it is not yet a multi-user public website.
To make likes/comments/accounts work for everyone online, the next step is to connect a backend/database and deploy the site with a domain.
